# QA · Plan de trabajos automático

- [ ] Planificación > Tabla muestra el botón "Generar plan de trabajos".
- [ ] Con un presupuesto vacío, la vista previa avisa que no hay tareas.
- [ ] Con un presupuesto de vivienda (Presupuesto rápido por rubros), la vista previa muestra los rubros en orden de obra, con instalación gruesa antes de revoques y terminación después de pisos.
- [ ] Cambiar la fecha de inicio corre todo el plan; el fin estimado cae en día hábil.
- [ ] Si el proyecto ya tenía vínculos, avisa cuántos se reemplazan.
- [ ] Tareas sin rendimiento: avisa cuántas son.
- [ ] "Aplicar plan": el Gantt muestra las barras encadenadas con sus líneas de dependencia y el fin coincide con la vista previa.
- [ ] Seguro, baño químico y auxiliares ocupan todo el plazo.
- [ ] Recargar la página: los vínculos y las fechas se mantienen.
- [ ] Editar a mano un vínculo o los frentes de una tarea después de aplicar funciona como siempre.
